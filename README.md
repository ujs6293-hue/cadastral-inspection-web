# cadastral-inspection 단독형 v0.4

설치 프로그램, Python, PC 서버 실행 없이 GitHub Pages의 HTTPS 주소에서 사용하는 시제품입니다. 선택한 도면과 AI 문자 인식은 브라우저 내부에서만 처리합니다. 기존 남색·청록색·주황색 디자인을 유지합니다.

## 홈페이지 주소

Pages 설정 후 접속할 주소: **https://ujs6293-hue.github.io/cadastral-inspection-prototype/**

이 문서는 배포 설정을 안내하며, GitHub 계정에 로그인해 실제 Pages 게시를 완료했다고 주장하지 않습니다.

## GitHub에 올리기

1. 제공한 ZIP을 풀어 `github-upload` 폴더를 엽니다.
2. 기존 저장소의 첫 화면에서 `Add file → Upload files`를 누릅니다.
3. `github-upload` 안의 **docs 폴더 전체**, README.md, LICENSE, THIRD_PARTY_NOTICES.md, .gitignore를 끌어 넣습니다. ZIP 자체나 github-upload 바깥 폴더를 올리지 마세요. 숨김 파일 `.gitignore`와 `docs/.nojekyll`도 포함하세요.
4. `브라우저 단독형 v0.4 추가`라고 적고 Commit changes를 누릅니다. 기존 설치형 소스는 남아 있어도 됩니다.
5. 저장소 `Settings → Pages → Build and deployment`에서 `Source: Deploy from a branch`, `Branch: main`, `Folder: /docs`를 선택하고 Save를 누릅니다. 실제 기본 브랜치 이름이 main이 아니면 해당 브랜치를 선택하세요.
6. 배포가 끝나면 Pages 화면의 Visit site를 누르세요. 처음에는 수 분 걸릴 수 있습니다. 해당 저장소의 Pages 사용 권한과 계정 플랜에 따라 설정이 제한되면 GitHub의 안내를 확인하세요. 공개 저장소로 바꿀 경우에는 소스만 있는지 먼저 확인하세요.

GitHub Code 화면의 HTML 파일을 누르는 것은 앱 실행이 아닙니다. 위 GitHub Pages 주소로 접속해야 합니다. `docs` 안의 상대 경로를 사용하므로 저장소 하위 경로에서도 동작합니다. 기존 `web` 폴더나 실행파일을 Pages 경로로 지정하지 마세요.

## 사용

최신 Edge·Chrome을 권장합니다. 첫 방문 시 사이트와 AI OCR 실행자료 약 40MB를 받습니다. AI 엔진 준비 버튼으로 엔진을 준비하거나, 파일 등록 후 자동판독으로 시작하세요. PDF·PNG·JPG·ZIP을 여러 개 등록하고 선택/전체 판독을 실행합니다. ZIP과 개별 파일은 128MB, ZIP 해제 합계 512MB, PDF 500쪽 제한입니다.

후보를 누르면 원본 페이지·인식 영역·문구·검토 근거를 확인합니다. 담당자·사유를 입력해 판단을 저장하고, 확인서·보고서를 HTML로 내려받아 인쇄/PDF 저장합니다. `자료 백업`은 원본·판독문·판단 이력을 포함하는 ZIP을 PC에 저장합니다. 현재 자동 복원 UI는 없으며 ZIP 안의 원본과 manifest.json을 별도로 보관할 수 있습니다.

## AI와 검토 범위

Tesseract LSTM 기반 한국어/영어 AI 문자 인식이 WebAssembly로 브라우저 안에서 실행됩니다. 인식한 비율식의 검산, 인쇄된 공차/오차 비교, 전자평판/위성측량 문구 병기 대조 후보를 제시합니다. PDF 내장 문자 검산과 이미지 AI OCR 결과는 방식을 구분합니다. OCR에서 읽지 못한 내용이 도면에 없다고 단정하지 않습니다.

생성형 이미지 AI·지적측량 전용 학습 모델·경계 접합·건물 누락·정밀 좌표·서명 진위의 종합 판정은 제공하지 않습니다. 기존 Windows용 Qwen 모델을 이 버전에서 실행한다고 주장하지 않습니다. 현행 법령·업무 매뉴얼 데이터는 미포함이며 별도 검증해야 합니다. 후보 없음은 적합이 아니며 시스템은 지적사항을 자동 확정하지 않습니다.

## PC 내부 처리와 저장

File API로 선택한 파일을 읽고 IndexedDB에 저장합니다. 파일을 서버에 업로드하는 API가 없습니다. 앱은 외부 CDN·클라우드 AI·원격 API·추적 코드를 사용하지 않습니다. 모든 실행자료와 학습자료는 docs/vendor에 동봉합니다. 처음에는 GitHub에서 정적 실행자료를 내려받으며, 도면을 다시 GitHub로 보내지는 않습니다. GitHub는 페이지 접속 시 일반적인 접속정보를 처리할 수 있습니다. 지도 버튼을 누르면 사용자가 입력한 검색어가 지도 서비스로 전달됩니다.

같은 PC라도 브라우저·접속 주소가 다르면 자료가 공유되지 않습니다. 기존 설치형/로컬 웹앱 DB와도 별개입니다. 시크릿 모드 종료·브라우저 데이터 삭제·저장공간 부족 시 자료가 사라질 수 있으므로 백업하세요. IndexedDB는 이 앱이 관리하는 별도 암호화 저장소가 아닙니다. 공용 PC에서는 사용 후 자료를 삭제하세요.

서비스 워커가 실행자료 캐시를 준비하면 새로 고침 후 같은 주소에서 오프라인 사용을 지원합니다. 캐시를 처음 만들 때는 인터넷이 필요합니다. 브라우저가 캐시를 삭제하거나 새 PC에서 접속하면 다시 내려받아야 합니다. 업데이트 후 구버전이 보이면 열어 둔 탭을 닫고 다시 접속하세요. 브라우저 데이터 전체를 지우면 도면도 삭제되므로 먼저 백업하세요.

## 공개자료

사용자 도면·매뉴얼·발췌문·확인서·보고서·개인정보·검사 DB·AI 응답은 포함하지 않습니다. vendor의 언어 학습자료는 공개 OCR 모델이며 사용자 업무자료가 아닙니다. 사용 후 생성한 도면·백업·로그·화면 캡처를 저장소에 추가하지 마세요. .gitignore는 GitHub 웹 업로드를 차단하지 않습니다.
