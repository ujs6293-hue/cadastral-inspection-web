설치 없는 브라우저 내부 처리

선택한 파일은 서버에 업로드하지 않습니다. PDF 처리와 Tesseract LSTM 기반 AI 문자 인식은 이 브라우저에서 실행됩니다. 생성형 이미지 AI나 지적측량 전용 학습 모델은 아닙니다.

공개용에는 실제 도면·매뉴얼·발췌문·업무 기준 데이터가 없습니다. 검토 근거는 명시된 식의 산술 계산, 도면에 적힌 공차/오차, 측량방법 문구 대조입니다. 법령 허용치를 자동 적용하지 않습니다.

후보 없음은 적합이 아닙니다. 현행 법령과 원본 매뉴얼은 담당자가 별도로 검증해야 하며, 자동 확정하지 않습니다. 경계·건물·좌표·서명 종합 AI 판단은 미구현입니다.

도면·판단은 이 브라우저의 IndexedDB에 저장됩니다. 같은 PC라도 브라우저나 접속 주소가 다르면 자료가 공유되지 않습니다. 이전 설치형 DB와 자동 연결되지 않습니다. 브라우저 데이터 삭제·시크릿 모드 종료·저장공간 부족 시 자료가 사라질 수 있으니 백업하세요.

처음 열 때 사이트와 OCR 실행자료 약 40MB를 내려받습니다. 준비가 끝나면 새로 고침 후 같은 주소에서 오프라인 사용도 지원합니다. 캐시가 삭제되면 다시 인터넷 연결이 필요합니다. 서버 실행이나 EXE 실행은 필요 없습니다.
